# 0035 — Remove `diceduel` from the catalog

Date: 2026-09-17
Status: Accepted
Decision: Deleted `public/games/diceduel/` entirely, its entry in `public/hub-config.json`, its row in `docs/GAMES_MAP.md`, and its classic-script-globals block in `eslint.config.mjs`; scrubbed its remaining mentions from `docs/BACKLOG.md`, `docs/NEW_GAME.md`, and `STATE.md` (left untouched in this file, which is append-only history).
Context: Mid-way through a consistency pass adding a "Règles" section to every custom game's Paramètres panel (Black Stories, Millionaire, Yatzy) plus fixing a real duplicate-language-switcher bug on la Bataille Corse (see `apps/coinchapp/STATE.md`), the audit found `diceduel` was the one game with zero i18n at all (every other game reads/writes the same `bergamots-lang` key; `diceduel` had no language code, hardcoded French throughout `engine.js`/`ui.js`/`main.js`, including combo names embedded directly in game logic). Before starting that translation work, the user asked to remove the game instead.
Rationale: Deletion is the simplest coherent action once translating is off the table — keeping a known-inconsistent, unmaintained game in the catalog would just leave the same audit finding for the next pass. Verified zero remaining references repo-wide (`git grep -il diceduel`) before/after, confirming nothing else depended on it (no shared module, no other game, no build config outside the two files removed).
Consequences: The hub tile grid drops from 15 to 14 custom+wordpack+external tiles; no other game's code or shared module was touched. `docs/BACKLOG.md`'s "oversized games needing a `NOTES.md`" and "split app.js, follow diceduel's precedent" entries no longer name it. `npm run lint`/`format:check`/`build` pass; the removal was verified live (`npm run dev`, hub grid, tile gone).
Alternatives_Rejected: Adding FR/EN/ES i18n to `diceduel` instead (the original plan) — superseded directly by the user's request; would have required decoupling combo display names from `engine.js`'s return values first, a bigger change than the other 3 games' rules-only additions.
