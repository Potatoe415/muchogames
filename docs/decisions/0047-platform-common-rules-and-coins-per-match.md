# 0047 — Platform common rules, enforced by check; one coin per match started

Date: 2026-10-03
Status: Accepted (supersedes the "one coin per hub launch" part of 0046)
Decision: Every game follows `docs/PLATFORM_RULES.md` — back button top-left (confirms "Quitter la partie ?" during a match), options gear top-right with language / rules / "Report a problem", one daily coin per match started (replays and online rematches included, opening a game is free), matches started / won / lost — enforced by `scripts/check-games.mjs` in `npm run check` and CI with a baseline that only shrinks. Coins move to one server-side counter per player across every game: the Google profile when signed in, else a random browser UUID (`muchogames-device-id`) the hub forwards to colocated apps as `?mgDevice=`. In-repo games use `public/shared/js/game-session.js` (`MuchogamesMatch`) over public `POST /api/match`; coinchapp/Tranquil call `start_muchogames_match` from their servers (coinchapp decision 0071). Games whose code is not in this repo declare `coinPolicy: "launch"` and are charged by the hub when opened. `/admin` ranks matches started (`match_start`); the hub launch tracker (`api/track.js`, `shared/js/analytics.js`) is removed.
Context: Owner request (2026-10-03): massively improve and homogenize the common rules for current and future games, written down and applied; coins only when a match is launched, not when a game is opened. Owner choices: Easy Frog/GameBoy keep paying at launch; anonymous coins server-side behind a device id; replays cost a coin; party games record "started" only; back confirms during a match; automated enforcement; online players each pay when the match actually starts, again on a rematch; no `*.vercel.app` URLs (coinchapp/Tranquil to move to `cartes.` / `tranquil.muchogames.win`).
Rationale: A written rule without a check drifts; the baseline lets the check land green on day one and forces each fix to shrink it. One SQL function spends, counts the match and logs the event atomically, so the hub, in-repo games and other apps cannot disagree. Anonymous counting had to leave the browser because coinchapp/Tranquil run on other origins. Every client fails open: a backend incident never blocks play.
Consequences: Opening a game is free; a match can be refused at its start screen. Anonymous players can still reset coins by clearing site data, and anyone knowing a device id can spend its coins (play pacing, not security). coinchapp/Tranquil need `ADMIN_USER_IDS` for an unlimited admin. Old `game_launch` rows and `bergamots-launch-counts` keys stay, unread. Tranquil is wired once its Vercel project is repointed; the last `*.vercel.app` launch URLs go once the subdomains exist.
Alternatives_Rejected: Per-browser anonymous counter (cannot be shared with other origins). Charging in coinchapp's server-side `startGame`/`rematchGame` (the server does not know each player's hub profile or device id). Keeping the hub launch charge for every game (double charge with per-match coins).
