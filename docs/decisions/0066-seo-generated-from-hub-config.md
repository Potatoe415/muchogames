# 0066 — SEO generated from `hub-config.json` at build time

Date: 2026-11-20
Status: Accepted
Decision: Every game entry in `public/hub-config.json` gets a French `description`. A Vite plugin, `scripts/seo.mjs`, reads the catalog at build time and produces: JSON-LD (`WebSite` + `ItemList` of `VideoGame`) and a crawlable footer listing every game with a real `<a href>` in `index.html`; `dist/sitemap.xml` and `dist/llms.txt` (both also served by `npm run dev`); and, in each copied `dist/games/<id>/index.html`, the `<title>` replaced by title + description + canonical (`https://www.muchogames.win/games/<id>/`) + Open Graph + `VideoGame` JSON-LD. Static: hub meta/OG/canonical in `index.html`, `public/robots.txt` (everyone allowed, AI crawlers included; `/api/` and `/admin` disallowed; sitemap line), wordplayer title/description, `noindex` on `/profile`. The footer heading/intro are translated by `hub-seo.js`.
Context: Owner request: make Muchogames easy to find on search engines and by LLMs. Before: no robots.txt, sitemap, description, OG or canonical; the hub's game list is rendered by JavaScript, so non-rendering crawlers (most LLM crawlers) saw only "Chargement des jeux...".
Rationale: One source of truth (the catalog) keeps a new game indexed with zero changes to `hub.js`, `vite.config.js` or the game's page. Game pages in `public/` are rewritten in `dist/` only, so the 29 sources and their formatting rules stay untouched. Descriptions in French only: the site's main language and the `lang="fr"` of every page; the hub UI around them stays FR/EN/ES.
Consequences: `description` is a required field (`docs/DATA_MODEL.md`, `docs/NEW_GAME.md`), not yet enforced by `scripts/check-games.mjs`. External games (coinchapp, Tranquil, GameBoy Web) appear in JSON-LD and `llms.txt` pointing to the hub, not in the sitemap (other hosts). Wordpack pages share `wordplayer.html`, so they get no canonical; their sitemap URLs carry `?game=`. Trademarked names (Scrabble, Tetris, Trivial...) are not used as keywords.
Alternatives_Rejected: Hand-editing the 29 game `<head>`s (drifts from the catalog, a new game forgets it); a static list inside `#hub-home` replaced by JavaScript (flashes 40 links on load, and rendered crawlers then lose every link because tiles are not anchors); server-side rendering (out of the vanilla stack).
