# 0040 — Admin access by allowlisted Google account

Date: 2026-10-02
Status: Accepted
Decision: `/admin` is reached by signing in with Google; the server admits only Supabase Auth user ids listed in `ADMIN_USER_IDS`, and the shared `ADMIN_PASSWORD` is removed.
Context: The owner wants an admin area for himself only, growing beyond read-only stats (feedback inbox, catalog, players — see `docs/tasks/platform-admin-profile-roadmap.md`). The shared password was still a demo value and gave no notion of who is acting. Google sign-in and a server-side Google → Supabase user exchange (`api/_lib/googleAuth.js`) already existed for `/profile`.
Rationale: Reuses the existing identity path instead of a second credential. User ids rather than emails, because a signed-in Supabase user can request an email change from the browser but never an id change. The session is the 1h Supabase access token returned by the same exchange, re-verified with `auth.getUser` on every admin action, so no signing secret or session table is needed. `api/admin/login.js` + `stats.js` merge into `api/admin/index.js` (dispatch on `action`, like `api/profile/index.js` in 0039), keeping the deployment at 9 of the 12 functions Vercel Hobby allows. A refused account is shown its own user id, which is how the owner finds the value to configure.
Consequences: Admin requires Google enabled as a Supabase Auth provider and `ADMIN_USER_IDS` set on each Vercel environment; without it nobody is admin (fail closed). `/admin` CSP now allows `https://accounts.google.com/gsi/` for script, style, frame and connect. `/api/profile` `get`/`upsert` return `isAdmin` so the hub can show an "Admin" link; that flag is display-only. Admin sessions expire after 1h and the owner signs in again.
Alternatives_Rejected: Keep the password as a fallback (owner chose Google only). Allowlist by email (mutable from the client). Own HMAC session token (needs a new secret or reuse of the service-role key). Verifying the Google ID token on every call (each call would mint a new Supabase session and hit Auth rate limits).
