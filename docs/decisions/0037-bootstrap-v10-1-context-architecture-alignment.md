# 0037 — Bootstrap v10.1 context architecture alignment

Date: 2026-09-22
Status: Accepted
Decision: Aligned this repo's context architecture with bootstrap prompt v10.1 (ALIGN mode, upgrading from the v9-style layout adopted in decision 0001): split the flat `docs/DECISIONS.md` into `docs/decisions/NNNN-slug.md` files + `docs/decisions/INDEX.md` (verbatim, one file per entry); added `docs/ARCHITECTURE.md` (merged from `docs/TECH.md`), `docs/SECURITY.md`, and `docs/DEBUGGING.md`; added `docs/_templates/` (module/task/decision templates) and `.claude/settings.json`; rewrote `AGENTS.md` and `STATE.md` to the v10.1 structure while keeping every Muchogames-specific rule (game-scoped work, `apps/<name>` self-governing sub-apps, `data-id`, size limits); condensed `docs/BACKLOG.md` (dropped the `Done` section, merged `Later` into `Next`). Applied the same pass to `apps/coinchapp` and `apps/tranquil` in the same session, at the user's explicit choice (all three at once, on `main`, no dedicated branch).
Context: The user supplied `bootstrap-prompt_v10.1.md` and asked to apply it to the project. This repo (and both colocated sub-apps) already used the AGENTS.md-centric protocol from bootstrap v9 (decision 0001 and its per-app equivalents), so this was the explicit "upgrade from bootstrap v9" path (bootstrap v10.1 §3.4), not a fresh CREATE.
Rationale: ALIGN mode's own rules (never overwrite; merge; keep what works) meant `docs/GAMES_MAP.md`, `docs/NEW_GAME.md`, and `docs/DATA_MODEL.md` were kept as-is and wired into the new `AGENTS.md` Context loading table rather than rewritten — this repo's real modularity boundary is per-game folders (`docs/GAMES_MAP.md`), not `src/modules/`, so no module tree was invented to match the template literally. The `docs/DECISIONS.md` → per-file split was done with a small parser script (not manual transcription) to guarantee verbatim wording/dates across 36 (root) + 61 (`coinchapp`) + 10 (`tranquil`) entries without transcription risk.
Consequences: `docs/TECH.md`, `docs/DECISIONS.md`, `CLAUDE.md`, and `.cursor/rules/000-router.mdc` are now superseded but kept on disk pending explicit user confirmation to delete (bootstrap ALIGN mode forbids autonomous deletion). Future decisions are logged as individual files under `docs/decisions/`, one per entry, indexed in `docs/decisions/INDEX.md`. No application code, game logic, or product scope changed in this pass.
Alternatives_Rejected: Doing only the root repo and leaving `apps/coinchapp`/`apps/tranquil` on the old v9 layout — rejected, the user explicitly chose all three in one pass. Creating a `src/modules/` tree to literally match the v10.1 template's module-map shape — rejected, this repo's actual modularity (per-game folders under `public/games/`, documented in `docs/GAMES_MAP.md`) already serves the same purpose and ALIGN mode explicitly forbids reorganising working code to fit a template. Deleting the superseded files immediately — rejected, ALIGN mode requires explicit user confirmation before any deletion.
