# 0038 — Match Coinchapp's floating back/settings button style hub-wide

Date: 2026-09-25
Status: Accepted
Decision: The shared `.back-button`/`.options-button` base rule in `public/shared/css/game-header.css` now renders exactly like Coinchapp's `HomeTopBar.tsx` control (36px circle, `rgba(0,0,0,.45)` background, white icon, `shadow-md`, `backdrop-blur(4px)`) instead of the old flat gray circle. Every game's back/options icon (previously a text glyph `←`/`⚙`) was swapped for the same inline SVG (arrow-left / gear) Coinchapp and Yatzy's splash already use, so the icon shape matches too, in `cafards`, `blackstories`, `olemains`, `pyramide`, `wordplayer.html` (taboo/esquisse/pigeonpigeon), and `public/profile/`. Tranquil's own `.icon-btn-float` (`apps/tranquil/client/src/index.css`) was resized/recolored to the identical `h-9 w-9`/`bg-black/45` values. Games that already deliberately re-skin these classes for their own theme (`cafards`' parchment palette, `blackstories`' dark palette, `pyramide`'s comic-book hard-shadow palette) keep their own background/border/shadow — only the base default and the icon shape changed, per the existing "games keep their own visual skin by overriding these rules" convention already documented in that CSS file. Millionaire's fully custom `.icon-button` (64px glass button, its own glyph set for home/restart/options) and every game's persistent in-game header row (Yatzy's `.game-settings-button`, Tranquil's `GameBoard.tsx` header) were left untouched — scoped by the user to "only the appearance of the back/settings buttons themselves," not a restructure of screens that have more chrome (timer, score, banner, opponent info) around them.
Context: User reported the back/settings buttons at the top of every app weren't uniform and asked for them to look exactly like Coinchapp's. Scoped with the user via `AskQuestion`: apply everywhere (not just splash screens), but only change the two buttons' own appearance, not surrounding layout.
Rationale: `public/shared/css/game-header.css` is the one shared contract file already read by every vanilla-JS game per `shared/CONTRACT.md` — editing its base rule propagates the fix without touching each game's markup for color, and Yatzy's splash button (`.splash-nav-btn`) turned out to already use these exact pixel/rgba/blur values, confirming them as the canonical target rather than inventing new numbers.
Consequences: Any future vanilla-JS game that doesn't override `.back-button`/`.options-button` gets Coinchapp's look for free. `cafards`/`blackstories`/`pyramide` still visually diverge in color/shadow (by design, pre-existing), but now share the same icon shape as everywhere else.
Alternatives_Rejected: Rebuilding every game's persistent in-game header (timer/score/banner rows) into a borderless floating-button layout like Coinchapp's splash screen — rejected per the user's explicit "everywhere, but only the button appearance" answer; would have been a much larger, riskier restructure of screens that aren't splash screens. Forcing `cafards`/`blackstories`/`pyramide`'s deliberately-themed button colors back to the plain black/45 default — rejected as undoing an existing, documented per-game skin decision the task didn't ask to revisit.
