# 0033 — Complete the `coinchapp` Vercel repoint: domain moved to `coinchapp-monorepo`, live in production

Date: 2026-09-17
Status: Accepted
Decision: `coinchapp.vercel.app` now serves `coinchapp-monorepo` (built from `Potatoe415/bergamots`'s `apps/coinchapp/`, via its Root Directory setting), not the original standalone `coinchapp` project. The domain was removed from the old project and added to the new one via two back-to-back API calls (Vercel refuses to have the same `*.vercel.app` domain on two projects at once, so there is no atomic "move" endpoint — the gap between the two calls was seconds, not verified as zero-downtime but not observed to fail either).
Context: Direct continuation of the in-progress `coinchapp` migration (`docs/BACKLOG.md`/`STATE.md`, prior entries this same day). User added `GIPHY_API_KEY` and `SUPABASE_SERVICE_ROLE_KEY` manually to `coinchapp-monorepo` (the two "sensitive"-type vars the agent could not copy) and said to continue.
Rationale: Before touching the live domain, verified end-to-end in a real browser rather than trusting a 200 on static pages: created an online game (exercises `SUPABASE_SERVICE_ROLE_KEY` + `NEXT_PUBLIC_SUPABASE_*` via a Server Action, not a REST route — Next.js Server Actions can't be curl'd meaningfully, hence the browser), filled it with bots (Supabase realtime broadcast), started the game (full game-state machine), and opened the GIF reaction picker (exercises `GIPHY_API_KEY`, returned real GIPHY results with the "Powered by GIPHY" attribution visible). Only once all four env vars were proven live did the domain move happen — matches this project's standing practice of live-verifying before calling a change done, and specifically avoids the failure mode flagged earlier in `docs/BACKLOG.md` (a Preview deployment 500ing because a required Supabase env var was missing).
Consequences: The old `coinchapp` Vercel project (`prj_hYpygjNbeeTmS2qnZzJEJVsY6hxw`) now has no domain attached — still exists, not yet deleted (see `docs/BACKLOG.md` Now). `docs/GAMES_MAP.md`'s "Colocated" table entry for `coinchapp` is no longer "in progress", it is live. The `Potatoe415/coinchapp` GitHub repo can now be archived (per the user's earlier decision to archive, not delete, once migrated) — `tranquil` is unaffected and still deploys from its own original repo. The Vercel token pasted in chat earlier in this session is still active and was used again here; it still needs rotating once the whole migration (including `tranquil`) is finished.
Alternatives_Rejected: Adding the domain to the new project before removing it from the old one — tried first, rejected by Vercel's API (`duplicate-team-registration`), confirming there genuinely is no atomic move for a `*.vercel.app` subdomain; removed-then-added was the only working order. Testing only static page loads (200 on `/`, `/coinche`) as "done" — rejected, that would not have caught a missing Supabase/Giphy env var, since those only fail inside a Server Action, not at page load.
