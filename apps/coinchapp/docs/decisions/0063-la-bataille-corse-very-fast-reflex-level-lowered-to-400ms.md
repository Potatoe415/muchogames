# 0063 — La Bataille Corse: "very fast" reflex level lowered to 400ms, own botThinkMs floor

Date: 2026-09-22
Status: Accepted
Decision: La Bataille Corse's discrete "reflex quality" slider (`BOT_REFLEX_LEVELS` in `GameSettingsPanel.tsx`) has its "very fast" level lowered from 800ms to 400ms, so all 4 levels now read as "slow >3s / normal >2s / fast >1s / very fast <0.5s". Since the shared `MIN_BOT_THINK_MS` (800ms, used by Coinche/Bouilla/Président) would otherwise clamp this back up, added a dedicated `MIN_BATAILLECORSE_BOT_THINK_MS = 400` (`lib/supabase/types.ts`) used only by this game's `botThinkMs` sanitizers: `sanitizeBotThinkMs` (`lib/server/actions-lobby.ts`, now takes an optional `min` param) for online, and `parseBotThinkMs` (`app/local/play/page.tsx`, same optional `min` param) for local.
Context: User asked to change the reflex difficulty thresholds; 3 of 4 levels already matched the requested wording, only "very fast" (800ms = 0.8s) didn't satisfy "< 0.5s".
Rationale: `MIN_BOT_THINK_MS` is deliberately 800ms for Coinche's ISMCTS search budget (decision 0039) - lowering it globally would let that budget go below its previously-fixed floor for every game. La Bataille Corse's `botThinkMs` isn't a search budget (`simulateBotReactionMs` just scales a random reaction-time window), so a lower, game-specific floor has no such downside and only affects this game.
Consequences: `games.settings.botThinkMs` can now persist as low as 400ms, but only when `gameType === "bataillecorse"` (`sanitizeSettings`'s bataillecorse branch passes the new floor explicitly). Every other game's sanitizer/parser call site is unchanged (implicit default `MIN_BOT_THINK_MS`). Ad-hoc P2P mode is unaffected (la Bataille Corse has no ad-hoc mode).
Alternatives_Rejected: Lowering the shared `MIN_BOT_THINK_MS` for every game (rejected - would silently let Coinche's ISMCTS budget go below its intentional 800ms floor, weakening bot play there for no requested reason).
