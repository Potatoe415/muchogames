# 0053 — La Bataille Corse: jokers reverted (52 cards, not 54), bot speed reframed as 4 discrete "reflex quality" levels

Date: 2026-09-16
Status: Accepted
Decision: Reversed the previous entry's 54-card-with-jokers option: `DeckSize` is now `32 | 52` (no jokers either way), `Rank` dropped `"JOKER"`, `PlayingCard.tsx`'s joker-glyph special case was removed, and `DEFAULT_BATAILLECORSE_DECK_SIZE` is back to a plain 52. Separately (same session), the settings-panel control that used to be the shared continuous "bot thinking time" slider is now, for la Bataille Corse only, a discrete 4-level "Qualité des réflexes du bot" slider (Lent/Normal/Rapide/Très rapide, mapped to `[3200, 2400, 1600, 800]` ms feeding the same `botThinkMs` setting/`simulateBotReactionMs` - no engine change, only how the value is picked in the UI).
Context: User explicitly asked to drop jokers immediately after they shipped ("c'est cinquante-deux cartes, oublie les jokers"), and separately asked for the bot-speed control to read as named reflex levels instead of a raw seconds slider, framed around "1, 2, 3, 4 -> lent, normal, rapide, très rapide".
Rationale: Jokers were an ordinary `Rank` value with no special-casing elsewhere in the engine (see the previous entry), so removing them was a clean, contained revert: `cards.ts`/`types.ts`/`PlayingCard.tsx` plus their tests, no other file's logic depended on `"JOKER"` existing. The reflex-quality slider reuses the exact same discrete-slider pattern already established for Président's `roundsToPlay` and the shared `stillThereTimeout`/`botPunch` controls (index into a fixed array, labeled ticks) rather than inventing a new UI idiom.
Consequences: `lib/bataillecorse`'s `Rank`/`DeckSize`/`buildDeck`/tests are back to a 32-or-52, no-joker shape (see docs/DATA_MODEL.md). `GameSettingsPanel.tsx` now renders two mutually exclusive bot-pacing controls depending on `bataillecorseFields`: the discrete reflex-quality slider for la Bataille Corse, the original continuous slider for every other game - both still write the same `GameSetupValues.botThinkMs`/`GameSettings.botThinkMs` field, so no other layer needed to change. No SQL migration.
Alternatives_Rejected: Keeping 54-with-jokers as a still-available third option alongside 32/52 (rejected - user said to forget jokers entirely, not add a third choice). A button-row (4 discrete buttons) instead of a slider for reflex quality (rejected in favor of matching the existing slider-with-labeled-ticks idiom already used for every other discrete setting in this panel).
