# 0072 — Fifth game: Solitaire (Klondike), solo and local only

Date: 2026-10-23
Status: Accepted
Decision: Add Solitaire (Klondike) as a fifth game, solo and offline only: no online room, no ad-hoc/P2P, no bot. The player picks draw 1 or draw 3 on `/solitaire`, which opens the shared `/local/play?game=solitaire&draw=1|3` route. Pure engine in `lib/solitaire/` (deal, draw/recycle, legal targets, moves, tap resolution), local state in `lib/client/useLocalSolitaireGame.ts`, table in `components/SolitaireTable.tsx` + `SolitairePiles.tsx`. A tap moves a card straight to its only legal destination; with several, the card is picked up and its destinations light up until the player taps one. Only a solved game is recorded (a win); giving up or starting over never counts as a loss.
Context: Owner request (2026-10-23): "rajouter le jeu de carte du Solitaire en réutilisant un max les composants de coinchapp". Owner picked: draw 1 or 3 chosen by the player, tap-to-move (no drag and drop), wins only, plus a hub tile.
Rationale: Reuses the shared base as-is: `TableShell` + `MatchGate` (one coin per match, "Quitter la partie ?"), `HomeTopBar`, `GameInfoButton`, `RulesModal`, `PlayingCard`/`CardBack`, `lib/cards`, `localGamePersistence`, `useRecordMatchResult`. Solitaire never reaches the `games` table, so `GameType` (the DB discriminator) is unchanged; `CoinchappGame` (`lib/profileGames.ts`, the hub ids) gains `solitaire` and now types `HomeTopBar`/`RulesModal`. Card size comes from overriding `--card-md-w` on the scene (7 columns across, tallest column down), no new primitive.
Consequences: `COINCHAPP_GAMES` has five ids, so hub profile sync and coins attribute Solitaire on its own. Moves apply locally on the same frame, so the instant-feel rule needs no optimistic hook. Like the other local games, restarting mid-match does not spend another coin; a new deal after a finished one does. A saved game resumes only when its draw count matches the mode picked. Hub: new `public/hub-config.json` entry and thumbnail.
Alternatives_Rejected: Add `solitaire` to `GameType` (would widen every server dispatch union for a game that never goes online). Always auto-move to a "best" destination (takes the choice away when a card fits on two columns, or on a column and a foundation). Count abandons as losses (owner choice).
